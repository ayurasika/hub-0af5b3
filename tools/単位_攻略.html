このページの 🟦面積 と 🧊かさ で、実際に「入っていくところ」を見てみよう。

📌 きほんの「実物アンカー」

単位を見たら、この実物を思い出す。テスト中の「答えがヘンじゃないか確認」に使える。

  • 🎲 1cm³ = 1mL … サイコロ1こ・角砂糖1こ
  • 🥛 1L … 牛乳パック1本（サイコロ1000こ分）
  • 🛁 お風呂1杯 … 約200L
  • 🧊 1m³ … 牛乳パック1000本！ お風呂5杯分
  • 🧺 1㎡ … 1人用レジャーシート（1m×1m）
  • 🏫 1a（アール）… 学校の教室 約1.5こ分
  • ⚾ 1ha（ヘクタール）… 学校の運動場ぜんぶくらい（甲子園のグラウンドで約1.3ha）
  • 🎡 1km² … 東京ディズニーランド 約2こ分
  • 🪙 1g … 1円玉1まい
  • 🥛 1kg … 牛乳パック1本（水1Lの重さ！）
  • 🚗 1t … 軽自動車1台くらい

🟦 面積ズームのぼり — 1㎡ から 1km² まで

面積の単位は、辺が10倍ずつ大きくなる正方形の階段。
1段のぼるごとに ×100（0が2こふえる）。

💡 ズームアウトすると、さっきまで見ていた正方形が「左下の1マス」になる。マスは全部で100こ（10×10）。これが「×100」の正体。

⚠️ 面積のひっかけポイント

・1㎡ = 10000cm²（100cm×100cmだから。「100cm²」じゃない！）
・a と ha の間だけ覚えにくい → 「㎡ → a → ha → km² ぜんぶ ×100」と一本の階段で覚えるとまちがえない。
・1ha = 10000㎡（a をとばして2段 = ×100×100）

🧊 その1：サイコロ1000こで牛乳パック（1L）

🎲 1辺1cmのサイコロ（1cm³ = 1mL）を、1辺10cmの箱に詰めていくよ。
何こ入るかな？
箱の大きさ：タテ10cm × ヨコ10cm × 高さ10cm　（1だん = 10×10 = 100こ）
1cm³ = 1mL×1000→ 1000cm³ = 1L 🥛

🧊 その2：牛乳パック1000本で 1m³

今度は 🥛牛乳パック（1L）を、1辺1mの大きな箱に詰めるよ。
さっきとまったく同じことが、1000倍のスケールで起きる。
箱の大きさ：タテ1m × ヨコ1m × 高さ1m　（1だん = 100本）
1mL = 1cm³×1000→ 1L×1000→ 1m³ = 1kL

🛁 お風呂1杯が約200L。1m³ = 1000L = お風呂5杯分の水が入る！

⚠️ かさのひっかけ：dL（デシリットル）

1mL×100 1dL×10 1L×1000 1kL=1m³

dLだけ階段の高さがちがう（1L = 10dL、1dL = 100mL）。「牛乳パックをコップ10ぱいに分けた1ぱい」が1dL。

⚖️ 重さの階段 — きれいに ×1000 ずつ

1mg×1000 1g 🪙×1000 1kg 🥛×1000 1t 🚗
  • 🐜 1mg … アリ1匹くらい（超かるい）
  • 🪙 1g … 1円玉1まい
  • 🎒 1kg … 1Lの牛乳パック1本（ランドセルは教科書入りで約4kg）
  • 🚗 1t … 軽自動車1台（ゾウは約5t）

💧 水のひみつ — かさと重さがつながる！

水は「かさの単位＝重さの単位」になる魔法の物質。
これを知ってると2つの単位がいっぺんに覚えられる。

🏃 速さの単位変身マシン

時速 → 分速 → 秒速 は ÷60、÷60。もどるときは ×60、×60。

📏 長さの階段 — ここだけ段の高さがバラバラ！

1mm×10 1cm×100 1m×1000 1km

重さ（×1000ずつ）とちがって、長さは 10 → 100 → 1000 と段の高さがちがう。ここがひっかけの巣。

  • 💅 1mm … つめの先のうすさ
  • 👆 1cm … 人さし指のはば
  • 🚪 1m … 大また1歩
  • 🚶 1km … 歩いて約15分

⏰ 時間 — 60進法のなかま

1秒×60 1分×60 1時間×24 1日

時間だけは10進法じゃない（×60、×60、×24）。だから速さの換算で ÷60 が出てくる。
0.5時間 = 30分、0.1時間 = 6分（60分の1/10）… 小数の時間に注意！
